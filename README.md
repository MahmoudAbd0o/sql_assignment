# Python Basics Exercises 🐍

A collection of 40 Python exercises covering the fundamentals of Python programming.

## Topics Covered

- Lists
- Dictionaries
- Sets
- Loops (`for`, `while`)
- Conditions
- Functions
- List Comprehension
- Basic Problem Solving
- Interactive Programs

## How to Run

Make sure Python 3 is installed, then run:

```bash
python python_basics_40_exercises.py
```

Choose an exercise from **1 to 40** from the main menu.

## Purpose

These exercises were created to practice Python fundamentals and improve problem-solving skills.
